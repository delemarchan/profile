# 📦 DELEMARCHAN BOX

> **Some boxes should remain closed.**

### 🇫🇷 × 🇧🇫 — Studio franco-burkinabè

Delemarchan Box est un studio indépendant consacré à une philosophie simple :

**Créer des expériences qui repoussent volontairement les limites du joueur.**

Des jeux difficiles.
Des jeux injustes.
Des jeux qui demandent de la patience.

Et parfois...

**des jeux qui donnent envie de continuer précisément parce qu'ils font mal.**

---

## 🩸 Notre philosophie

Chez Delemarchan Box, nous ne cherchons pas nécessairement à rendre nos jeux agréables.

Nous cherchons à les rendre **intenses**.

La frustration devient une mécanique.
La douleur devient une récompense.
L'échec devient une étape.

Parce qu'il existe une étrange frontière entre :

> **souffrir pour avancer**

et

> **prendre plaisir à souffrir.**

C'est précisément cette frontière qui nous intéresse.

# 🔥 Ultimate Fakir Game

### `UFG`

**Status:** `🚧 IN DEVELOPMENT`

Un jeu construit autour d'une idée très simple :

### **Jusqu'où êtes-vous prêt à aller ?**

UFG transforme la difficulté en spectacle.

Chaque obstacle est pensé pour tester :

* 🧠 votre patience
* 🎯 votre précision
* 🩸 votre capacité à recommencer
* 🫀 votre tolérance à l'échec

Le but n'est pas seulement de terminer le jeu.

Le but est de voir **ce qu'il vous faudra sacrifier pour y parvenir.**
